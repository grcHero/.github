**grcHero** is one connected workspace for the systems you run and the proof that you run them
well: assets, architecture, risks, controls, framework requirements, policies and evidence. It
helps you see what your product depends on, find the gaps worth closing first, and keep the
evidence with the work, so a security review or audit starts from what you already have.

### Check your project from the terminal

The [grcHero CLI](https://github.com/grcHero/cli) reviews Dockerfiles, CI workflows and the files
you choose, right on your machine. Your code never leaves it. Results come back as clear
observations you can act on, save, or send to your workspace.

```sh
# macOS and Linux
curl -fsSL https://grchero.dev/install.sh | sh
```

```powershell
# Windows (PowerShell)
irm https://grchero.dev/install.ps1 | iex
```

Releases are checksummed and signed. See [installation](https://grchero.dev/docs/cli/installation)
and the [command reference](https://grchero.dev/docs/cli/commands).

### Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature in the
affected repository's Security tab, never in a public issue. See the CLI's
[security policy](https://github.com/grcHero/cli/blob/main/SECURITY.md).
